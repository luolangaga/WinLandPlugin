# 开机时长（uptime-clock）

WinIsland（Windows 11 灵动岛）插件。

- **小岛**：圆圈进度（24 小时一圈，转满重新转）+ 开机时长
- **展开**：开机时长、CPU 温度、本次开机时间
- **点击岛体**：超级展开卡片 —— 大圆环、温度、本次/上次开机记录

## 设置

- 在灵动岛上显示（开关）
- 温度刷新间隔（2–300 秒，默认 5）

## 说明

- CPU 核心温度通过 LibreHardwareMonitorLib 读取；通常需要 **WinIsland 以管理员身份运行**才能读到，
  读不到时温度显示「—」，其余功能不受影响。
- 上次开机记录来自「系统」事件日志（事件 6005/6006）。

## 开发

项目根目录的 `global.json` 把构建 SDK 钉在 .NET 10（与宿主一致），**不要删除或修改**。
在项目目录里 `dotnet build`，构建成功后自动部署到本机 WinIsland 的 `plugins\uptime-clock\`。
