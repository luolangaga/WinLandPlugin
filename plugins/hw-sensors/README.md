# 硬件传感器（hw-sensors）

在灵动岛上实时看 CPU / GPU 的温度、功耗和占用，外加整机预估功耗、电池电量和损耗程度。
使用可靠的开源项目组件，后续出新型号CPU理论上只需更新组件即可适配。

## 它能显示什么

**小岛（紧凑态）**：图标 + 名称 + 一个最关键的值，例如 `52°C · 14W`。

**大岛（展开态）**：四行明细，每行都能单独开关。

<img width="947" height="701" alt="预览-卡片展开" src="https://github.com/user-attachments/assets/f782c998-1a06-4731-9a34-f6220447c823" />


| 硬件 | 内容 | 图标 |
| --- | --- | --- |
| CPU | 温度 / 功耗 / 占用 | CPU 芯片 |
| GPU | 温度 / 功耗 / 占用 | 显示器 |
| 整机 | 整机预估功耗（电池供电时是实测值） | 闪电 |
| 电池 | 电量 / 充放电功率 / 预计充满 / 损耗 | 电池（随电量变档） |

温度 ≥ 85°C 时数字变暖红，一眼能看出是不是过热了。

**点一下岛**：打开聚光卡，里面是完整明细 —— CPU 和 GPU 各自的温度、热点温度、功耗、占用，整机功耗的算法说明，电池的设计容量 / 满充容量 / 电压 / 充放电功率 / 预计充满时间 / 损耗程度。

## 数据从哪来（不需要管理员权限）

灵动岛宿主本身是普通权限进程，所以这个插件全程走**免管理员通道**：

| 指标 | 数据源 |
| --- | --- |
| GPU 温度 / 功耗 / 占用 | LibreHardwareMonitor（NVIDIA / AMD / Intel 显卡驱动直接给） |
| 电池电量 / 容量 / 电压 / 充放电功率 / 损耗 | LibreHardwareMonitor 电池组 |
| CPU 封装功耗 | RAPL 能耗性能计数器（`\Energy Meter(*)\Power`，Windows 自带） |
| CPU 温度 | ACPI 热区性能计数器（`\Thermal Zone Information`，Windows 自带） |
| 充放电方向、交流供电状态 | `GetSystemPowerStatus`（Windows 自带） |

> **关于 CPU 温度**：Windows 不开放 AMD 的 Tctl/Tdie 精确结温给普通权限进程（那要装内核驱动）。插件用的是主板 ACPI 热区温度，读数和 CPU 负载强相关，日常够用，但它是「整机热区」而不是「CPU 核心结温」，所以聚光卡里标注成「整机热区」。

**整机预估功耗**怎么算：
- 电池供电时 → 直接用电池的放电功率，**是实测值**（标注「电池实测」）
- 交流供电时 → CPU + GPU + 固定基线（标注「估算」）。基线默认 8W，可在设置里按自己机型微调（屏幕、内存、硬盘、风扇等都在这里面）

## 设置页

灵动岛设置 → 插件 → 硬件传感器：

- **在灵动岛上显示** —— 总开关，关掉后整个卡片从岛上撤走
- **CPU / GPU / 整机 / 电池** —— 四项独立开关，关掉的项目不再采样，展开态也会跟着变矮，不留空白
- **显示电池损耗程度** —— 台式机可以关掉（台式机默认也没电池可显示）
- **显卡下拉** —— 多显卡机器（独显 + 核显）可以指定监控哪一块，默认优先独显
- **整机功耗基线** —— 0~200W，默认 8W
- **采样间隔** —— 500~30000 毫秒，默认 2000
- **立即刷新 / 检测数据源** —— 后者会把每个数据源的实际读数打到设置页上，方便排查

## 安装

把 `hw-sensors.lwp` 拖进灵动岛，或在灵动岛设置里点「安装插件」选这个文件。

要求 WinIsland ≥ 2.4.0。

## 兼容性

- 台式机：没有电池，电池那行自动不显示，其余功能正常
- 多显卡：默认优先 NVIDIA 独显，可在设置里切换
- 虚拟机 / 无独显的机器：CPU 部分靠 RAPL 和 ACPI 热区，大多数 x86 机器都支持；如果某个数据源不可用，对应数字显示 `--`，不会让整张卡崩掉
