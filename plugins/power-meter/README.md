# 功耗计

实时监测整机的耗电功率（瓦 W）与累计耗电（度/kWh），在 WinIsland 灵动岛常驻显示，点击岛体可展开聚光卡查看详细统计。

## 功能

- 灵动岛常驻显示：实时功率 + 电量百分比（放电 / 充电 / 插电估算三种状态自动切换）
- 聚光卡统计：统计起点、累计度数、平均功率、最近 12 小时逐小时耗电时间轴、最近 7 天每日耗电
- 设置页：一键清零并重新开始统计

## 统计口径

- **用电池时**：功率 = 电池充放电电流，是整机实测值，最准。
- **插电时**：Windows 测不到整机功率，按「CPU 占用率 × 本机校准系数」估算，公式为 `功率 ≈ A + B × CPU%`：
  - 显卡部分走 NVIDIA NVML 读独显实时瓦数（系统自带 nvml.dll，免管理员）；无 NVIDIA 独显时该项为 0。
  - 屏幕部分按当前亮度折算（WMI 读亮度，免管理员）。
- **自动校准**：插电估算的 A、B 系数来自「电池放电期间的实测数据」回归。用得越久、不同负载都跑过，插电估算越准。想校准更快：拔掉电源用一会儿电池（轻载重载都跑跑），再插回去即可。

## 权限与依赖

- **免管理员、零配置、零弹窗、无需安装任何驱动或服务**。所有数据来自系统自带接口（电池报告 API、CPU 占用率、NVML、WMI 亮度）。
- 不依赖任何后台计划任务或第三方采集器，适合直接发布与安装。

## 用法

1. 安装后在 WinIsland 灵动岛即可看到功耗计；
2. 设置 → 插件管理 可开关显示、或将统计清零；
3. 点岛体打开聚光卡看完整统计。
